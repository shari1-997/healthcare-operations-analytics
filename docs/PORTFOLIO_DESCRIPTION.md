# Portfolio Description

## LinkedIn project title

Healthcare Operations Analytics | MySQL & Power BI

## Short description

Built a four-page healthcare operations and financial analytics dashboard using MySQL and Power BI. The project covers 8,000 appointments, 1,500 patients, 5,760 billing records, 3,470 payment transactions, 60 doctors, and 10 departments. I used SQL to load and validate relational data, developed DAX measures for operational and financial KPIs, and designed interactive report pages for appointment performance, patient insights, billing analysis, and revenue trends.

## Key responsibilities / work demonstrated

- Created and populated a six-table MySQL database from CSV source files.
- Validated row counts, missing key fields, duplicate bill IDs, foreign-key references, and billing/payment reconciliation using SQL.
- Built Power BI relationships across appointments, patients, doctors, departments, billing, and payments.
- Developed DAX measures for appointment completion, cancellation, average waiting time, billed amount, posted payments, outstanding balance, and payment collection rate.
- Created four interactive dashboard pages with year slicers and separate billing-date and payment-date analysis.
- Preserved missing booking-channel and insurance-plan categories as `Unknown` rather than excluding those records.

## Skills

MySQL | SQL | Power BI | DAX | Power Query | Data Cleaning | Data Validation | Data Modelling | KPI Reporting | Dashboard Design

## Portfolio note

This is a portfolio analytics exercise using healthcare-themed sample data. It is not a clinical decision-support system and should not be represented as analysis of a real provider unless the data provenance supports that claim.
